This one file is the entire input. Everything else — the brand voice, the banned-word list, the internal-link map, the byline, the topic queue, the brand assets, and the site itself — is generated from it.

  1. Save business.config.yaml to the root of the site repo.
  2. Set ANTHROPIC_API_KEY in the repo's Actions secrets. Nothing that writes prose runs without it.
  3. Run npm run derive. This writes all seven artifacts. It is the only build step.
  4. Read content/brand/voice.md and the first ten topics before anything publishes. That review is the one step no amount of automation replaces — everything downstream inherits whatever the voice file says.
  5. Run npm run dry to confirm the site builds without spending anything, then dispatch the publish workflow once by hand and watch it go live.
  6. Run npm run verify against the live domain. It must pass 100%.

Re-running npm run derive later is safe: hand-edits to the voice file and the topic queue are detected and left alone unless you pass --force. To add topics once the queue runs low, use --only=queue --append — never --force, which would re-add everything already published.
